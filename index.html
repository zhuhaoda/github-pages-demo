02 / FROM FILE TO WEBSITE

从本地到上线，只要三步。

GitHub 官方指南 ↗
01

创建一个公开仓库

登录 GitHub，新建一个 Public 仓库，例如 github-pages-demo。只放示范页面，不放私密文件。

02

放入这个网页

把 index.html 上传到仓库根目录。文字、样式和交互都在这一份文件里，不需要安装任何依赖。

03

开启 GitHub Pages

进入 Settings → Pages，选择 Deploy from a branch，再选 main 和 /(root)。保存后等待发布。
